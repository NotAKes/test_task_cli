# CLI Векторный Редактор

Консольное приложение для управления геометрическими фигурами. 
Разработано в рамках первого этапа тестового задания.

## Технологический стек
* **Язык:** Python 3.10+

## Архитектурные решения
Проект спроектирован с учетом принципов SOLID и разделен на логические слои:
1. `shapes.py` - Слой моделей данных. Использованы `dataclasses` и абстрактные базовые классы (`abc`) для создания строгого контракта `Shape`. Реализована композиция (сложные фигуры используют базовый класс `Point`).
2. `canvas.py` - Слой бизнес-логики (Менеджер состояния). Инкапсулирует хранилище фигур (словарь для доступа за O(1)) и логику генерации уникальных ID.
3. `cli.py` - Слой интерфейса. Реализован на базе встроенного модуля `cmd` для обеспечения отказоустойчивого цикла ввода, парсинга команд и автогенерации документации.

## Запуск приложения

Склонируйте репозиторий и запустите главный файл:

`bash`
`git clone <ссылка_на_ваш_репозиторий>`
`cd <папка_проекта>`
`python cli.py`


## Доступные команды
Внутри оболочки редактора (приглашение `>`) доступны следующие команды:

* `create <тип> <параметры>` - создание новой фигуры.
  * Поддерживаемые типы: `point`, `line`, `circle`, `square`.
  * *Пример:* `create circle 0 0 15` (создаст круг с центром 0,0 и радиусом 15).
* `list` - вывод списка всех созданных фигур с их ID.
* `delete <id>` - удаление фигуры по ее ID.
* `help` - вывод списка всех команд.
* `help <команда>` - подробная справка по конкретной команде.
* `exit` - корректное завершение работы программы.
